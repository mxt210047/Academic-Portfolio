## Featured project · THE GRIND

A web hub that tracks the four things I actually spend time on: **internships, sports, anime, and Xbox**. Applications move across a mission board, Dallas scores sit on a sideline ticker, the watch queue logs episodes, and the Xbox library records sessions. Everything feeds one Gamerscore.

Open [`the-grind/`](./the-grind/) and run `python3 server.py`, then visit `http://127.0.0.1:4173`. Full notes are in [`the-grind/README.md`](./the-grind/README.md).
