# Form I-9 Review Checklist

Complete one pass per form. Log every “No” / deficiency in `FINDINGS_TRACKER.csv`.

## A. File presence & identity match

- [ ] Form I-9 exists for this employee
- [ ] Employee name on Form matches payroll / identity records (or documented legal name change)
- [ ] First day of employment on Section 2 matches payroll hire date (or difference explained)
- [ ] Form edition was unexpired/valid as of the date Section 2 was completed
- [ ] Pages / supplements required for that edition are present (including Lists of Acceptable Documents if retained with the form per your process)

## B. Section 1 — Employee information and attestation

Must be completed **no later than the first day of employment** (never before a job offer is accepted).

- [ ] Full legal name completed
- [ ] Other last names used (or N/A / intentionally blank per then-current instructions)
- [ ] Address completed as required by the form edition used
- [ ] Date of birth completed
- [ ] U.S. Social Security number completed if required (e.g., E-Verify employers)
- [ ] Employee attestation box checked (citizen / noncitizen national / LPR / alien authorized to work)
- [ ] Alien / USCIS / A-Number / I-94 / expiration fields completed when attestation requires them
- [ ] Employee signed and dated Section 1
- [ ] Preparer/translator certification completed if someone assisted (Supplement A when applicable)
- [ ] No employer-completed fields improperly filled in Section 1

## C. Section 2 — Employer review and verification

Must be completed **within 3 business days** of the first day of employment (same day if employment lasts fewer than 3 business days).

- [ ] Employee’s first day of employment entered
- [ ] Either **List A** **or** **List B + List C** documented (not both List A and B/C unless correcting a documented error)
- [ ] Document title, issuing authority, document number, and expiration (if any) recorded as required
- [ ] Documents recorded were acceptable under the Lists in effect at verification time
- [ ] List B document is photo ID if employer is/was enrolled in E-Verify (when applicable)
- [ ] Employer / authorized representative signed and dated Section 2
- [ ] Employer business name and address completed
- [ ] Timing: Section 2 signature date is on or before day 3 business day after start
- [ ] If a receipt was used, follow-up document recorded when due

## D. Section 3 / Supplement B — Reverification & rehires

- [ ] Reverification completed before work authorization expired (when required)
- [ ] Reverification not performed for U.S. citizens or for List B identity documents
- [ ] Rehire entries completed when required by the form instructions
- [ ] Name changes recorded when using Section 3 / Supplement B for that purpose
- [ ] Authorized representative signed and dated reverification / rehire block

## E. Retention & storage

Retention: **later of** 3 years after hire date **or** 1 year after termination date.

- [ ] Form retained for the full retention period
- [ ] Terminated-employee forms destroyed/securely disposed only after retention ends (per policy)
- [ ] Electronic storage (if used) meets integrity, access, and audit-trail expectations
- [ ] I-9s stored separately from general personnel files **or** otherwise protected per policy (recommended practice)

## F. E-Verify (only if enrolled / required)

- [ ] Case created within 3 business days of start date for new hires (when required)
- [ ] Case result documented / closed properly
- [ ] Tentative Nonconfirmation (TNC) procedures followed without adverse action during resolution window
- [ ] Photo matching completed when prompted

## Quick severity cues

| Finding | Typical class |
|---------|----------------|
| Typo in address; transposed digit later corrected | Technical |
| Missing employee signature/date in Section 1 | Substantive |
| Section 2 completed late | Substantive |
| No Form I-9 on file for current employee | Substantive |
| Wrong document recorded / List A + B improperly combined | Substantive |
| Retention past destruction date with no policy | Process |
| E-Verify case never opened | Substantive / Process |
